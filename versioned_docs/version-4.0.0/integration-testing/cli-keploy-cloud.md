`keploy cloud` replays an app's recorded tests and manages the Keploy branch of each pull request. Authors usually start with `keploy cloud status`, and reviewers with `keploy cloud review list`.

## Environment variables

| Variable                  | Used for                                                                                                               |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `KEPLOY_API_KEY`          | Sign in without a browser, in CI or locally. `--api-key` overrides it for one command.                                 |
| `KEPLOY_K8S_PROXY_URL`    | Self-hosted clusters: the k8s-proxy's ingress URL. Sends every command through the cluster's proxy.                    |
| `KEPLOY_TLS_SKIP_VERIFY`  | Accept a self-signed certificate on a self-hosted proxy.                                                               |
| `KEPLOY_K8S_PROXY_AUTH`   | Set to `false` to turn off proxy authentication when `KEPLOY_K8S_PROXY_URL` is set but the cluster is on Keploy Cloud. |
| `KEPLOY_APPROVAL_TIMEOUT` | Default for `replay --approval-timeout`.                                                                               |
| `KEPLOY_REQUIRE_APPROVAL` | `true` makes `replay` fail at once on an unapproved branch, as `--require-approval` does.                              |
| `KEPLOY_AUTO_BRANCH`      | `false` makes `replay` stay on main, as `--no-auto-branch` does.                                                       |

Most commands accept `--app <namespace>.<deployment>`, `--cluster <name>` (optional when you have one cluster), `--k8s-proxy-url` and `--json`.

## For pull-request authors

### `keploy cloud status`

Where a pull request stands with Keploy: its newest CI replay run, its Keploy branch and review, and what to do next

| Flag                       | Description                                                                                                                                    |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `--app` `string`           | App the pull request's runs are looked up for, as namespace.deployment (default: the Keploy branch's app, or a self-hosted cluster's only app) |
| `--cluster` `string`       | Cluster name (default: the only connected cluster)                                                                                             |
| `--json`                   | Print the NEXT block as one JSON object                                                                                                        |
| `--k8s-proxy-url` `string` | Self-hosted cluster's k8s-proxy URL (default: KEPLOY_K8S_PROXY_URL, else the ingress the cluster's latest heartbeat reports)                   |
| `--pr` `int`               | Pull request number (default: inside CI, the run's own; else the checkout's, when gh can tell, or found by the checkout's git branch)          |
| `--repo` `string`          | The pull request's repository, as owner/name (default: the checkout's)                                                                         |

```bash
keploy cloud status
keploy cloud status --pr 412 --repo acme/shop
```

### `keploy cloud triage`

Explain a failed cloud replay run, one group of failures at a time

| Flag                       | Description                                                                                                                                                                                        |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--app` `string`           | App as namespace.deployment (required, except with --group/--verdict)                                                                                                                              |
| `--cluster` `string`       | Cluster name (default: the only connected cluster)                                                                                                                                                 |
| `--commit` `string`        | Look the run up by commit (default: inside CI, the commit the run is recorded for; else HEAD)                                                                                                      |
| `--group` `string`         | Group to record an answer for (with --run and --verdict)                                                                                                                                           |
| `--json`                   | Print the NEXT block as one JSON object                                                                                                                                                            |
| `--k8s-proxy-url` `string` | Self-hosted cluster's k8s-proxy URL (default: KEPLOY_K8S_PROXY_URL, else the ingress the cluster's latest heartbeat reports)                                                                       |
| `--path` `string`          | The repo's keploy directory (default: keploy at the top of the git checkout, wherever in it the command runs; outside a checkout, ./keploy); the cache goes in .keploy-triage/ beside it           |
| `--pr` `int`               | Look the run up by pull request number (default: inside CI, the run's own; else the current branch's PR, when gh can tell)                                                                         |
| `--refresh`                | Download the run again instead of reading the cache                                                                                                                                                |
| `--repo` `string`          | Look the run up in this repository only, as owner/name: a PR number is unique only per repository (default: inside CI, the run's own; else the current branch's PR's repository, when gh can tell) |
| `--run` `string`           | Test run ID to triage (printed in the CI job's step summary)                                                                                                                                       |
| `--verdict` `string`       | The user's answer for --group: regression, intended or not-code                                                                                                                                    |

```bash
keploy cloud triage --run tr-8f2c --app shop.orders
keploy cloud triage --pr 412 --app shop.orders
keploy cloud triage --run tr-8f2c --group G1 --verdict intended
```

### `keploy cloud accept`

Delete a triaged run's intended failures on the PR's Keploy branch and request review

| Flag                          | Description                                                                                                                                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--abandon-attempt` `strings` | Test set whose delete lost its answer and, you have checked, never reached its tests (repeatable): the attempt is dropped so the group can be deleted on the right --branch or answered again |
| `--already-deleted` `strings` | Test set whose intended tests were deleted by hand (repeatable): a delete there that finds none of them on the branch counts as done instead of being refused                                 |
| `--app` `string`              | App as namespace.deployment (default: the app the run was triaged for)                                                                                                                        |
| `--branch` `string`           | Keploy branch to delete on, by name (in the run's app) or id (default: the branch the run used)                                                                                               |
| `--cluster` `string`          | Cluster name (default: the cluster the run was triaged for)                                                                                                                                   |
| `--json`                      | Print the NEXT block as one JSON object                                                                                                                                                       |
| `--k8s-proxy-url` `string`    | Self-hosted cluster's k8s-proxy URL (default: KEPLOY_K8S_PROXY_URL, else the ingress the cluster's latest heartbeat reports)                                                                  |
| `--path` `string`             | The repo's keploy directory (default: keploy at the top of the git checkout, wherever in it the command runs; outside a checkout, ./keploy)                                                   |
| `--reviewer` `strings`        | Email or user id of a reviewer to request review from (repeatable). Without one, no review is requested: the NEXT block lists who may review                                                  |
| `--run` `string`              | The triaged run (required)                                                                                                                                                                    |

```bash
keploy cloud accept --run tr-8f2c --app shop.orders
keploy cloud accept --run tr-8f2c --app shop.orders --reviewer asha@acme.io
```

### `keploy cloud restore-test`

Bring back a test your Keploy branch deleted by mistake, as a new commit

| Flag                       | Description                                                                                                                                                                                              |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--app` `string`           | App as namespace.deployment: the app a --branch name is looked up in (on a self-hosted cluster, needed unless it lists you only one app; on SaaS, needed with a branch name, and it narrows review list) |
| `--branch` `string`        | The branch: its name with --app (a branch name is unique in its app), or its id. 'keploy cloud review list' prints both (required)                                                                       |
| `--cluster` `string`       | Cluster name (default: the only connected cluster)                                                                                                                                                       |
| `--json`                   | Print the NEXT block as one JSON object                                                                                                                                                                  |
| `--k8s-proxy-url` `string` | Self-hosted cluster's k8s-proxy URL (default: KEPLOY_K8S_PROXY_URL, else the ingress the cluster's latest heartbeat reports)                                                                             |
| `-m`, `--message` `string` | The commit's message (default: Restore &lt;test&gt;); with several tests, each commit's is &lt;message&gt; (&lt;test&gt;)                                                                                |
| `--test` `stringArray`     | A deleted test as &lt;test set&gt;/&lt;test&gt;, or a deleted test set's name (repeatable); without one, the NEXT block lists what the branch deletes                                                    |

```bash
keploy cloud restore-test --app shop.orders --branch feat/greet --test test-set-0/get-items-by-id-2
keploy cloud restore-test --app shop.orders --cluster prod --branch feat/greet --test test-set-0/get-items-by-id-2 -m "The 404 wording change was reverted"
```

| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--app` `string`           | App as namespace.deployment: the app a --branch name is looked up in (on a self-hosted cluster, needed unless it lists you only one app; on SaaS, needed with a branch name, and it narrows review list) |

| `--json`                   | Print the NEXT block as one JSON object                                                                                                                                                                  |
| `--k8s-proxy-url` `string` | Self-hosted cluster's k8s-proxy URL (default: KEPLOY_K8S_PROXY_URL, else the ingress the cluster's latest heartbeat reports)                                                                             |

## Branch maintenance

### `keploy cloud branch-commit`

Commit a test-data branch's pending changes

| Flag                           | Description                                                                                                                                                                                                             |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--app` `string`               | App identity (required) — UUID for non-proxy apps OR namespace.deployment for proxy apps (e.g. '--app prod.orders' or '--app 1a2b…')                                                                                    |
| `--branch` `string`            | Branch name to commit (auto-detected from CI if omitted)                                                                                                                                                                |
| `--cluster` `string`           | Cluster the app is recorded on (required with --k8s-proxy-url / k8s-proxy-auth mode; otherwise needed with --app &lt;namespace.deployment&gt; when that name exists on more than one cluster)                           |
| `-c`, `--config-path` `string` | Path to the local directory where keploy.yml is stored (default ".")                                                                                                                                                    |
| `--k8s-proxy-url` `string`     | Self-hosted k8s-proxy ingress URL. Setting it (or KEPLOY_K8S_PROXY_URL) commits through the cluster's proxy, where a self-hosted app's branches live; requires --app &lt;namespace&gt;.&lt;deployment&gt; and --cluster |
| `-m`, `--message` `string`     | commit message (default "committed by keploy CLI")                                                                                                                                                                      |

```bash
keploy cloud branch-commit --app <app-id|namespace.deployment> --branch feat/my-feature
```

### `keploy cloud branch-merge`

Merge a test-data branch into main

| Flag                           | Description                                                                                                                                                                                                            |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--app` `string`               | App identity (required) — UUID for non-proxy apps OR namespace.deployment for proxy apps (e.g. '--app prod.orders' or '--app 1a2b…')                                                                                   |
| `--base-branch` `string`       | The git branch Keploy's main follows, as for cloud replay's catch-up (default main): a pull request into another branch merges its Keploy branch once its change reaches this one.                                     |
| `--branch` `string`            | Branch name to merge (auto-detected from CI if omitted)                                                                                                                                                                |
| `--bypass-review`              | Merge without the required approval. Org admins only; recorded on the branch timeline and the pending reviewers are told.                                                                                              |
| `--cluster` `string`           | Cluster the app is recorded on (required with --k8s-proxy-url / k8s-proxy-auth mode; otherwise needed with --app &lt;namespace.deployment&gt; when that name exists on more than one cluster)                          |
| `-c`, `--config-path` `string` | Path to the local directory where keploy.yml is stored (default ".")                                                                                                                                                   |
| `--force`                      | Merge a pull request's Keploy branch without checking that the pull request has merged (it merges after the pull request, never before).                                                                               |
| `--k8s-proxy-url` `string`     | Self-hosted k8s-proxy ingress URL. Setting it (or KEPLOY_K8S_PROXY_URL) merges through the cluster's proxy, where a self-hosted app's branches live; requires --app &lt;namespace&gt;.&lt;deployment&gt; and --cluster |

```bash
keploy cloud branch-merge --app <app-id|namespace.deployment> --branch feat/my-feature
```

## Replay

### `keploy cloud replay`

Replay tests in the cloud or locally from cloud

| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--allow-egress` `strings`         | What the replay may reach on the real network (repeat or comma-separated). "dns" forwards a DNS query no mock answers to the host's and public resolvers too; without it a miss is forwarded only to a resolver inside the replay's own network (docker's, the container network's or the cluster's)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `--allow-stale-base`               | Suppress the warning printed when the working tree is behind --base-branch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `--allow-stale-branch`             | Exit 0 even when the Keploy branch is behind main. The divergence is still reported; only the non-zero exit is suppressed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `--api-key` `string`               | Keploy API key for this invocation (overrides KEPLOY_API_KEY env)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `--api-timeout` `uint`             | User provided timeout for calling its application (default 5)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `--app` `string`                   | App name (namespace.deployment) — required, K8s/proxy apps only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `--app-name` `string`              | Name of the user's application                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `--approval-timeout` `duration`    | How long a pull-request run whose tests pass waits for its Keploy branch to be approved before it fails. (default 30m0s)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `--assert-dependencies`            | Fail a test whose recorded per-test dependency was NOT observed during that test's window (an expected, mapped, non-reusable-tier mock went unconsumed): FAILED status, failed test set, non-zero exit. Unlike --strict-failure (which promotes only tests whose RESPONSE also failed) this catches the response-matched-but-dependency-vanished case. ELIGIBILITY: only per-test-tier mocks are asserted; untagged HTTP/Postgres/MySQL egress is session-tier and is excluded, so for such a recording nothing is eligible and every test reports dependencies_checked=false (NOT CHECKED, not clean). keploy logs one warning per test set naming the reason whenever the assertion cannot run. Full contract: the assertDependencies doc in config.                          |
| `--base-branch` `string`           | Branch the PR will merge into. Cloud replay warns when the working tree is behind it, because failures may then reflect changes you have not merged in. (default "main")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `--base-path` `string`             | Custom api basePath/origin to replace the actual basePath/origin in the testcases; App flag is ignored and app will not be started &amp; instrumented when this is set since the application running on a different machine. Write it as an http or https URL with a host (http://staging:8080/api) or as a path prefix (/api). Its host and port are where the HTTP tests are sent, under that host's name (test.host is not used, a test.port still replaces the port); gRPC tests go to that host on the port they were recorded on (or test.grpcPort). No outgoing call is mocked                                                                                                                                                                                                                                                                                                                                       |
| `--branch` `string`                | Test data branch name (auto-detected from CI if not set)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `--branch-id` `string`             | Keploy branch ID (uuid) to scope the replay to. Mutually exclusive with --branch-name / --create-branch; all optional (no flag → main).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `--branch-name` `string`           | Keploy branch name to scope the replay to. CLI resolves name → id internally. Mutually exclusive with --branch-id / --create-branch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `-b`, `--build-delay` `uint`       | User provided time to wait docker container build (default 30)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `--channel-binding-shim`           | Enable the eBPF channel-binding shim: on replay, downgrade libpq channel_binding=require→disable so SCRAM-SHA-256-PLUS apps replay against trust-mode mocks. Needs the enterprise cbshim agent image. | `--ci-commit-sha` `string`         | Override CI commit SHA                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
